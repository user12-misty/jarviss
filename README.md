# Jarvis - Basic Voice Assistant

Jarvis is a simple voice assistant built with Python that performs basic tasks using voice commands.

## Features

- 🎤 Voice recognition
- 🔊 Text-to-speech
- 🌐 Open websites
- 🔍 Search Google
- 📖 Search Wikipedia
- 🕒 Tell date and time
- 💻 Open applications

## Technologies

- Python
- SpeechRecognition
- pyttsx3
- Wikipedia
- PyAudio
